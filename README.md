# Internet Banking • Acessibilidade TEA

Protótipo estático em HTML, CSS e JavaScript para simular o pagamento total ou mínimo de uma fatura e comparar três casos de acessibilidade.

## Executar

Na pasta do projeto:

```sh
python3 -m http.server 8000
```

Abra `http://localhost:8000` no navegador.

## Projeto final de acessibilidade

Na tela inicial, escolha **Pagar fatura** e siga as etapas de escolha do valor,
revisão e comprovante. Os cartões em **Comparar os casos** abrem as telas com a
alternância entre Problema e Solução. Os controles de fonte e contraste estão no cabeçalho.
O VLibras e a fotografia precisam de conexão à internet.
