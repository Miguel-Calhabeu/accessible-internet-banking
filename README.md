# Internet Banking • Acessibilidade TEA

Protótipo estático em HTML, CSS e JavaScript. Inclui os três casos, a comparação entre problema e solução e as telas de revisão, comprovante e modo foco presentes no arquivo do Figma.

## Executar

Na pasta do projeto:

```sh
python3 -m http.server 8000
```

Abra `http://localhost:8000` no navegador.
